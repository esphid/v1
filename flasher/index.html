Install ESPHID

Turns an ESP32-S3 board into a USB keyboard and mouse that your phone drives over Bluetooth, WiFi, Tailscale or MQTT. Flash it from this page in about a minute.

Pick your board

The module name is printed on its metal shield, for example ESP32-S3-WROOM-1-N16R8. Match the part after the last dash.

Flash

This browser can't talk to USB devices. Open this page in Chrome or Edge on a computer.

USB access needs a secure page. Open this page over https.

Steps

  1. Plug the board into this computer. For the first install either USB port works. To re-install later over the port marked USB (not UART), hold BOOT while plugging it in, because ESPHID uses that port as a keyboard.

  2. Click Connect and install, choose the serial port, and keep the tab open until it finishes.

  3. Plug the board's USB port into the computer you want to control. It appears as a keyboard and mouse.

  4. Set it up. Open the ESPHID app and pick the device over Bluetooth, or join the ESPHID-XXXXXX WiFi network on any phone or laptop and follow the page that opens.

Later updates install over the air from the app or the device's own page. All releases
